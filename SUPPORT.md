# Support

## Getting Help

- **Documentation:** start with the repository README and any docs/ folder.
- **Questions and ideas:** use GitHub Discussions when enabled for the repository.
- **Bugs and feature requests:** open an issue using the provided templates.
- **Security issues:** follow `SECURITY.md` and report privately. Do not open public issues.
